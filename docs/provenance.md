Provenance

Everything in this repository is either drawn from a named public source or authored here.

**Substrate — public.** Schemas under `examples/governed_warehouse/warehouse/` come from a public text-to-SQL benchmark: table structures, column types, seed data shape, and reference queries where they exist.

**Governance layer — authored.** Restriction flags, access matrix, scan-cost ceilings, the constraint set, enumerated interpretations, and all task instances were written for this repository. The source benchmark measures SQL difficulty; demur measures policy adherence and abstention, and the layer that makes that measurable does not exist upstream.

**Instances.** Hand-written, some LLM-drafted against the authoring guideline and individually reviewed. Never generated by the system under test or the judge model. Instances carry an `origin` field — this bears on validity, since machine-drafted cases can inherit the drafting model's blind spots about what counts as ambiguous.

Extend as categories are added. If something fits none of the above, reconsider the addition rather than adding a heading.
